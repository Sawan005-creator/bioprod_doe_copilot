# bioprod_doe_copilot
MVP Definition: DOE Copilot for Academic Bioprocess Labs
the Problem it solves : Researchers running bioprocess/fermentation experiments choose which variable combinations to test either by intuition/one-factor-at-a-time (statistically weak, wastes runs) or by wrestling with expensive, unfriendly software (Design-Expert, Minitab, MODDE) that assumes a stats background most biotech-trained researchers don't have.
"Early-stage student project — DOE copilot for bioprocess labs. Currently: basic full-factorial design generator.
